Batteries included tree-sitter highlighting library that generates a
[hast](https://github.com/syntax-tree/hast) tree from input code and language.

This started out as a fork of [tree-sitter-highlight npm package](https://github.com/devongovett/tree-sitter-highlight) and contains a superset of official [Tree-sitter Highlight](https://github.com/tree-sitter/tree-sitter/tree/master/highlight) library.
